# Code of Conduct

## Our standard

We want Monandroid to be a respectful, technically serious, and welcoming open-source project.

Examples of behavior that help create a positive environment:

- being respectful in disagreement
- assuming good intent while staying honest
- giving actionable technical feedback
- helping newer contributors onboard
- keeping discussions focused on the code, product, and users

Examples of unacceptable behavior:

- personal attacks or insults
- harassment or intimidation
- discriminatory language
- doxxing or sharing private information
- bad-faith disruption of issues, reviews, or community spaces

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, commits, or other contributions that violate this Code of Conduct.

## Scope

This Code of Conduct applies to project spaces such as:

- issues
- pull requests
- discussions
- review comments
- community translation work

## Reporting

If a conduct issue occurs and a private maintainer contact is available, use it. If a private route is not yet published, avoid escalating publicly and wait for the maintainers to define one.

## Moderation principles

- protect contributors from harassment
- prioritize evidence over escalation
- de-escalate where possible
- keep enforcement proportional to the behavior
